Reveal elements as they scroll into view.

Narleaf Reveal animates elements as the page scrolls. Add one attribute, include a stylesheet and a script, and you're done.

Quick start

Two files and one attribute. Nothing to build or configure.

  1. Include the files

    <link rel="stylesheet" href="narleaf-reveal.css" />
<script src="narleaf-reveal.js" defer></script>

  2. Add an attribute to any element

    <div data-nar-reveal="slide-left">Hello</div>

  3. Adjust it with more attributes, if you want

    <div data-nar-reveal="zoom-in-center"
     data-nar-reveal-delay="300"
     data-nar-reveal-duration="900">
  Hello
</div>

Effects

26 effects in seven families. Select one to preview it. The value says which side the element comes from. An empty or unknown value simply fades in.

slide-left

Combine effects by nesting

One element carries one effect. To combine two, nest them: here the outer element slides up and the text inside wipes in a moment later.

<div data-nar-reveal="slide-bottom">
  <span data-nar-reveal="clip-right"
        data-nar-reveal-delay="400">
    Nested
  </span>
</div>

Delay and duration

Delay is how long to wait before starting. Duration is how long the animation runs. Both are in milliseconds, and the defaults are 0 and 800.

<div data-nar-reveal="slide-left"
     data-nar-reveal-delay="300"
     data-nar-reveal-duration="800">
  ...
</div>

On the tracks, a dashed line is the wait and a solid bar is the animation.

Distance

Slide, zoom and bounce travel 200 px by default. Set data-nar-reveal-distance in pixels, on an element or on a wrapper to cover everything inside it. An element's own value wins.

<div data-nar-reveal-distance="60">
  <div data-nar-reveal="slide-left">60 px</div>
  <div data-nar-reveal="slide-left"
       data-nar-reveal-distance="240">240 px</div>
</div>
Default, 200 px
From the wrapper, 60 px
Its own value, 240 px

Easing

Easing shapes how the speed changes over time. Use any CSS timing function: a keyword, cubic-bezier() or steps(). Invalid values are ignored. Each curve shows progress over time.

<div data-nar-reveal="slide-left"
     data-nar-reveal-easing="cubic-bezier(.2,.8,.2,1)">
  ...
</div>

The bounce effects already have their overshoot built in, so they look best with the default easing.

Stagger

Put data-nar-reveal-stagger on a wrapper and its direct children start that many milliseconds apart. No per-item delays to write.

It staggers the elements that appear together. In a long list, each group that scrolls into view starts again from zero, so nothing waits for the whole list. An element's own delay is added on top.

<ul data-nar-reveal-stagger="120">
  <li data-nar-reveal="slide-bottom">One</li>
  <li data-nar-reveal="slide-bottom">Two</li>
  <li data-nar-reveal="slide-bottom">Three</li>
</ul>

Trigger point

By default an element starts as soon as it touches the screen. Set data-nar-reveal-trigger on an element or any wrapper to wait for it to reach a zone. The shaded band is where the element has to be.

<section data-nar-reveal-trigger="center">
  <div data-nar-reveal="fade">...</div>
  <div data-nar-reveal="fade">...</div>
</section>

Very fast scrolling, or jumping with an anchor link, can skip the narrow bands. The element plays when you scroll back to it.

Play once, or again

An element plays once by default. Set data-nar-reveal-loop to a number to allow that many plays, or to infinite. Once an element is more than 300 px off screen it resets and can play again.

Scroll the cards out of view and back to watch the counters.

<div data-nar-reveal="zoom-in-center"
     data-nar-reveal-loop="2">...</div>

<div data-nar-reveal="zoom-in-center"
     data-nar-reveal-loop="infinite">...</div>

Content added later

Elements added after the page loads aren't picked up on their own. Call window.narReveal() after adding them. Pass a container to limit the work: the container itself counts too, and elements that are already set up are skipped.

const card = document.createElement('div');
card.dataset.narReveal = 'slide-bottom';
list.append(card);

window.narReveal(list);

Safe by default

Animations should never cost you content. These cases are handled without any setup.

JavaScript is off, blocked or fails

Elements are only hidden once the script reports it is ready. Until then, and if anything goes wrong, everything is shown.

Reduced motion

When the visitor asks for reduced motion, elements still appear as they are reached, without moving.

Printing

Every element is shown on paper.

Browsers without IntersectionObserver

The content appears without animation.

Nothing left behind

After an animation ends the element carries no leftover transform, so your own hover, transform and position rules keep working.

Set defaults in CSS

Change the defaults for the whole page, or for a wrapper. An attribute on an element or wrapper always wins over these.

Anything else is plain CSS. To repeat an animation forever, for example, add animation-iteration-count: infinite.

:root {
  --nar-reveal-distance: 120px;
  --nar-reveal-easing: cubic-bezier(.2, .8, .2, 1);
}
